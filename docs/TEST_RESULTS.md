## 확인 범위

- 직접 구현한 동적 배열, 이중 연결 리스트, 체이닝 해시맵, 인덱스가 있는 최소 힙.
- 필수 명령 10개와 Redis 스타일의 문자열·정수·배열·오류 출력.
- UTF-8 바이트 메모리 계산, 기존 값 교체, LRU 순서와 메모리 상한 축소.
- 단일 항목 OOM 오류 발생 시 기존 값·TTL·LRU 상태 보존.
- 가짜 시계를 이용한 만료 경계, TTL 재설정·초기화, 삭제 후 재삽입.
- 큰 정수 만료 기간을 포함한 64비트 숫자 인수와 잘못된 숫자 입력.
- 명령 파싱, 대화형 입력, 파이프 입력, 종료 명령과 입력 종료.

시간이 흐르기를 기다리는 테스트 대신 시계를 주입해 만료를 재현합니다. 따라서 경계 시각을 결정적으로 확인할 수 있습니다.

과제 예시의 메모리 제한 30바이트 시나리오도 직접 실행해 `user:1`이 제거되고 `used_memory:22`, `maxmemory:30`, `evicted_keys:1`이 출력되는 것을 확인했습니다.

로컬 통과는 위 환경에서의 결과입니다. Python 3.8·3.13의 원격 자동 검증 결과는 저장소의 Actions 화면에서 확인합니다.
